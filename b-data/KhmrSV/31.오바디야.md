# 31.오바디야 (KhmrSV)



## 1장

**1:1** នេះ​ជា​និមិត្ត‌ហេតុ​ដ៏​អស្ចារ្យ ដែល​ព្រះ‌ជាម្ចាស់​សម្តែង​ឲ្យ​លោក​អូបា‌ឌា​ឃើញ គឺ​ជា​ព្រះ‌បន្ទូល​របស់​ព្រះ‌ជា‌អម្ចាស់​អំពី​ស្រុក​អេដុម។<br>ព្រះ‌អម្ចាស់​ប្រទាន​ដំណឹង​មក​ពួក​យើង<br>ព្រះ‌អង្គ​ចាត់​អ្នក​នាំ​ពាក្យ​ម្នាក់​ឲ្យ​ទៅ<br>ប្រកាស​ក្នុង​ចំណោម​ប្រជា‌ជាតិ​ទាំង‌ឡាយ​ថា:<br>“ចូរ​ក្រោក​ឡើង នាំ​គ្នា​វាយ​សម្រុក<br>ចូរ​វាយ​លុក​ស្រុក​អេដុម​ទៅ!”។  
**1:2** «យើង​នឹង​ធ្វើ​ឲ្យ​អ្នក​ក្លាយ​ទៅ​ជា<br>ប្រជា‌ជាតិ​មួយ​តូច​ជាង​គេ<br>ជា​ប្រជា‌ជាតិ​មួយ​ដែល​គេ​មើល‌ងាយ​បំផុត។  
**1:3** ចិត្ត​អួត‌អាង​របស់​អ្នក បាន​បញ្ឆោត​ខ្លួន​ឯង<br>អ្នក​រស់​នៅ​តាម​ក្រហែង​ថ្ម<br>និង​នៅ​តាម​កន្លែង​ខ្ពស់ៗ<br>អ្នក​នឹក​ថា “គ្មាន​នរណា​អាច​ទម្លាក់​ខ្ញុំ<br>ចុះ​ទៅ​ដី​បាន​ទេ!”។  
**1:4** ទោះ​បី​អ្នក​ឡើង​ទៅ​លើ ខ្ពស់​ដូច​សត្វ​ឥន្ទ្រី<br>ទោះ​បី​អ្នក​លើក​ទ្រនំ​របស់​អ្នក​ទៅ<br>ដាក់​នៅ​ក្នុង​ចំណោម​ផ្កាយ​ក្ដី<br>ក៏​យើង​ច្រាន​អ្នក​ឲ្យ​ធ្លាក់​ចុះ​ដល់​ដី​វិញ​ដែរ<br>- នេះ​ជា​ព្រះ‌បន្ទូល​របស់​ព្រះ‌អម្ចាស់។  
**1:5** ប្រសិន​បើ​មាន​ចោរ​លួច​ចោរ​ប្លន់​ចូល​មក​ក្នុង​ផ្ទះ<br>របស់​អ្នក​នៅ​ពេល​យប់<br>នោះ​អ្នក​នឹង​បាត់​បង់​អ្វីៗ​ទាំង​អស់!<br>គេ​នឹង​លួច​យក​អ្វីៗ​ដែល​គេ​អាច​យក​បាន។<br>ប្រសិន​បើ​ពួក​បេះ​ផ្លែ​ទំពាំង‌បាយជូរ<br>មក​ដល់​ស្រុក​អ្នក<br>គេ​មិន​ទុក​ឲ្យ​មាន​ផ្លែ​នៅ​សល់​ឡើយ។  
**1:6** អេសាវ​អើយ គេ​គាស់​កកាយ​ស្រុក​អ្នក<br>ហើយ​ប្រមូល​យក​កំណប់​ទ្រព្យ​របស់​អ្នក។  
**1:7** បក្ស‌សម្ព័ន្ធ​របស់​អ្នក​នឹង​ដេញ​អ្នក<br>ចេញ​ពី​ទឹក​ដី​របស់​ខ្លួន។<br>មិត្ត‌ភក្ដិ​របស់​អ្នក​បោក​បញ្ឆោត​អ្នក<br>ហើយ​យក​អ្នក​ធ្វើ​ជា​នគរ​ចំណុះ។<br>ពួក​ដែល​បរិភោគ​អាហារ​ជា​មួយ​អ្នក<br>នាំ​គ្នា​ដាក់​អន្ទាក់​ចាប់​អ្នក<br>ទាំង​ពោល​ថា អ្នក​លែង​មាន​អ្នក​ប្រាជ្ញ​ហើយ។  
**1:8** ពិត​មែន​ហើយ នៅ​ថ្ងៃ​នោះ យើង​នឹង​បំបាត់<br>អ្នក​ប្រាជ្ញ​ឲ្យ​អស់​ពី​ស្រុក​អេដុម<br>ហើយ​បំបាត់​អ្នក​ឈ្លាស‌វៃ​ឲ្យ​អស់​ពី​ភ្នំ​អេសាវ<br>- នេះ​ជា​ព្រះ‌បន្ទូល​របស់​ព្រះ‌អម្ចាស់។  
**1:9** ក្រុង​ថេម៉ាន​អើយ ទាហាន​ដ៏​អង់‌អាច​របស់​អ្នក<br>នឹង​ភ័យ​ញ័រ​រន្ធត់<br>ខ្មាំង​សម្លាប់​រង្គាល​ទាហាន​ទាំង​ប៉ុន្មាន<br>នៅ​ភ្នំ​នៃ​ស្រុក​អេសាវ​អស់​គ្មាន​សល់!  
**1:10** អ្នក​នឹង​ត្រូវ​អាម៉ាស់ និង​វិនាស​រហូត<br>ព្រោះ​តែ​អំពើ​ឃោរ‌ឃៅ​ដែល​អ្នក​បាន​ប្រព្រឹត្ត<br>ចំពោះ​យ៉ាកុប ជា​ប្អូន​របស់​អ្នក។  
**1:11** នៅ​ថ្ងៃ​ដែល​ខ្មាំង​កៀរ​កង​កម្លាំង​របស់<br>អ៊ីស្រា‌អែល​ទៅ​ជា​ឈ្លើយ<br>នៅ​ពេល​ដែល​សាសន៍​ដទៃ​ចូល​តាម​ទ្វារ<br>ក្រុង​យេរូ‌សាឡឹម<br>រឹប​អូស​យក​អ្វីៗ​ក្នុង​ទីក្រុង​ចាប់​ឆ្នោត​ចែក​គ្នា<br>អ្នក​ក៏​នៅ​ទី​នោះ ហើយ​ប្រព្រឹត្ត​ដូច​ពួក​គេ​ដែរ។  
**1:12** នៅ​ថ្ងៃ​ដែល​ប្អូន​របស់​អ្នក​ត្រូវ​អន្តរាយ<br>អ្នក​មិន​គួរ​ឈរ​មើល ទាំង​មាន​អំណរ​ដូច្នេះ​ទេ<br>នៅ​ថ្ងៃ​ដែល​កូន​ចៅ​យូដា​វិនាស<br>អ្នក​មិន​គួរ​អរ​សប្បាយ​ឡើយ<br>នៅ​ថ្ងៃ​ដែល​គេ​រង​ទុក្ខ​វេទនា<br>អ្នក​មិន​គួរ​ហា​មាត់​ជេរ​ប្រមាថ​ដូច្នេះ​សោះ!  
**1:13** នៅ​ថ្ងៃ​ប្រជា‌រាស្ត្រ​របស់​យើង​ជួប​មហន្ត‌រាយ<br>អ្នក​មិន​ត្រូវ​ចូល​ទៅ​ក្នុង​ក្រុង​របស់​គេ​ទេ។<br>នៅ​ថ្ងៃ​គេ​ជួប​មហន្ត‌រាយ<br>អ្នក​មិន​ត្រូវ​ឈរ​មើល​ទាំង​មាន​អំណរ<br>ដោយ​ឃើញ​គេ​រង​ទុក្ខ​វេទនា។<br>នៅ​ថ្ងៃ​គេ​ជួប​មហន្ត‌រាយ<br>អ្នក​មិន​ត្រូវ​ឆ្លៀត​លួច​យក​ទ្រព្យ‌សម្បត្តិ<br>របស់​គេ​ឡើយ។  
**1:14** អ្នក​មិន​ត្រូវ​ចាំ​ស្កាត់​នៅ​តាម​ផ្លូវ​បំបែក<br>ដើម្បី​ប្រល័យ​ជីវិត​អ្នក​ដែល​រត់​គេច​ខ្លួន<br>នៅ​ថ្ងៃ​គេ​ជួប​អាសន្ន<br>អ្នក​មិន​ត្រូវ​ប្រគល់​អស់​អ្នក​ដែល​បាន​រួច​ជីវិត<br>ទៅ​ក្នុង​កណ្ដាប់​ដៃ​របស់​ខ្មាំង​ឡើយ!»។  
**1:15** ថ្ងៃ​ដែល​ព្រះ‌អម្ចាស់​វិនិច្ឆ័យ​ទោស<br>ប្រជា‌ជាតិ​ទាំង​អស់ ជិត​មក​ដល់​ហើយ<br>ព្រះ‌អង្គ​នឹង​ប្រព្រឹត្ត​ចំពោះ​អ្នក<br>ដូច​អ្នក​បាន​ប្រព្រឹត្ត​ចំពោះ​អ្នក​ដទៃ​ដែរ។<br>អ្នក​នឹង​ទទួល​ទោស​តាម​អំពើ​អាក្រក់​របស់​ខ្លួន!   
**1:16** «ចំណែក​ឯ​អ្នក​រាល់​គ្នា​វិញ អ៊ីស្រា‌អែល​អើយ<br>អ្នក​រាល់​គ្នា​បាន​ផឹក​ពី​ពែង​នៃ​ទុក្ខ​ទោស<br>នៅ​លើ​ភ្នំ​ដ៏‌វិសុទ្ធ​របស់​យើង​គ្រប់​គ្រាន់​ហើយ។<br>នៅ​ពេល​ខាង​មុខ ប្រជា‌ជាតិ​ទាំង​អស់<br>ក៏​នឹង​ផឹក​ពី​ពែង​នេះ​ឥត​ឈប់​ឡើយ<br>ពួក​គេ​ផឹក​រហូត​ទាល់​តែ​ស្រវឹង<br>ហើយ​វិនាស​សូន្យ​ទាំង​អស់​គ្នា។  
**1:17** អស់​អ្នក​នៅ​សេស‌សល់​ពី​ស្លាប់​នឹង​នាំ​គ្នា​មក<br>រស់​នៅ​លើ​ភ្នំ​ស៊ីយ៉ូន​ដែល​បាន​វិសុទ្ធ​ឡើង​វិញ<br>កូន​ចៅ​យ៉ាកុប​នឹង​យក​ទឹក​ដី<br>ដែល​សត្រូវ​ដណ្ដើម​បាន​នោះ​មក​វិញ។  
**1:18** កូន​ចៅ​យ៉ាកុប​នឹង​ប្រៀប​ដូច​ជា​ភ្លើង<br>កូន​ចៅ​យ៉ូសែប​ប្រៀប​ដូច​ជា​អណ្ដាត​ភ្លើង<br>រីឯ​កូន​ចៅ​អេសាវ​នឹង​ប្រៀប​ដូច​ជា​ចំបើង<br>ដែល​ត្រូវ​ភ្លើង​ឆាប​ឆេះ<br>ហើយ​ក្នុង​ចំណោម​កូន​ចៅ​របស់​អេសាវ<br>គ្មាន​នរណា​ម្នាក់​បាន​រួច​ជីវិត​ឡើយ»<br>ដ្បិត​ព្រះ‌អម្ចាស់​មាន​ព្រះ‌បន្ទូល​ដូច្នេះ។  
**1:19** ប្រជា‌ជន​យូដា​នឹង​កាន់​កាប់​តំបន់​ណេកិប<br>គឺ​ភ្នំ​របស់​អេសាវ<br>ពួក​គេ​នឹង​គ្រប់‌គ្រង​លើ​ស្រុក​វាល<br>ជា​ទឹក​ដី​របស់​ជន‌ជាតិ​ភីលីស្ទីន។<br>ព្រម​ទាំង​គ្រប់‌គ្រង​លើ​ស្រុក​សាម៉ារី<br>ជា​ទឹក​ដី​របស់​អេប្រាអ៊ីម។<br>រីឯ​កុល‌សម្ព័ន្ធ​បេន‌យ៉ាមីន<br>នឹង​គ្រប់‌គ្រង​លើ​ស្រុក​កាឡាដ។  
**1:20** ជន‌ជាតិ​អ៊ីស្រា‌អែល​ដែល​មាន​ចំនួន​យ៉ាង​ច្រើន<br>ហើយ​ត្រូវ​ខ្មាំង​កៀរ​ទៅ​ជា​ឈ្លើយ​នោះ<br>នឹង​កាន់​កាប់​លើ​ស្រុក​កាណាន<br>រហូត​ដល់​សារិប‌តា។<br>ប្រជា‌ជន​ក្រុង​យេរូ‌សាឡឹម​ដែល​ជាប់​ជា​ឈ្លើយ<br>នៅ​សេផា‌រ៉ាដ<br>នឹង​គ្រប់‌គ្រង​លើ​ក្រុង​នានា​នៅ​តំបន់​ណេកិប។<br>អ្នក​រំដោះ​ស្រុក​នឹង​ឡើង​ទៅ​លើ​ភ្នំ​ស៊ីយ៉ូន<br>ហើយ​ត្រួត‌ត្រា​លើ​ភ្នំ​របស់​អេសាវ<br>ហើយ​ព្រះ‌អម្ចាស់​នឹង​គ្រង​រាជ្យ។
